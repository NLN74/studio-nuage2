# Vérifications

La suite automatisée couvre les empreintes de mot de passe, les sessions, la déconnexion, les tentatives limitées, la configuration HTTPS, la protection des routes et écritures, les sauvegardes, les imports, la restauration, l’export, les styles, les gestes et les positions de carte.

Le navigateur a vérifié le refus d’un mauvais mot de passe, la connexion, le retour à une adresse automatique après réouverture d’un point manuel enregistré et la sauvegarde de ce résultat. Les essais sont réalisés dans une copie séparée.
