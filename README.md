# Nuage Studio — version Immersive

[Ouvrir le site](https://nln74.github.io/studio-nuage2/)

Site de présentation du studio de Pilates au sol à Sevrier. Huit pages, affichage mobile, planning interactif et parcours de réservation de démonstration.

Les coordonnées, créneaux et tarifs sont fictifs. Les paragraphes descriptifs sont en lorem ipsum. Les photos sont des illustrations générées. Les formulaires ne transmettent aucune donnée et aucun paiement n’est possible. Le site reste en noindex tant que les informations réelles ne sont pas validées.

Le logo original est conservé. Cormorant Garamond et Manrope servent de polices de remplacement en attendant le fichier web Eyesome.

GitHub Pages publie la branche main, à la racine. Les pages et les images sont autonomes, sans service externe.
