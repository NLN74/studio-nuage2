# Nuage Studio — version immersive

[Ouvrir le site](https://nln74.github.io/studio-nuage2/)

Site de présentation du studio de Pilates au sol à Sevrier : cinq pratiques accessibles depuis l’accueil, présentation du lieu, tarifs et contact Instagram.

Les réservations et le planning sont destinés à Eversports. L’intégration des nouveaux widgets et les liens de réservation, de cours et de produits sont préparés dans les sources du projet. Tant que les liens et l’identifiant du widget ne sont pas renseignés, la page Planning annonce l’ouverture prochaine des réservations et propose le contact Instagram. Aucun calendrier ni formulaire de réservation local n’est utilisé.

Contact : [@nuage.studiosevrier](https://www.instagram.com/nuage.studiosevrier/), avec un lien vers la conversation en message privé.

Les tarifs, coordonnées et textes descriptifs sont encore illustratifs. Les photographies sont des visuels de présentation. Le site reste en noindex tant que les informations réelles ne sont pas validées. Le logo original est conservé ; Cormorant Garamond et Manrope servent de polices de remplacement en attendant le fichier autorisé Eyesome.

GitHub Pages publie la branche main à la racine. Ce dépôt ne contient que les fichiers publics compilés ; les sources, la configuration et le guide Eversports sont conservés dans le dossier Nuage-Studio.

## Administration du site

Le dossier [admin-app](admin-app/README.md) contient le panneau complet, sa connexion par mot de passe, ses tests et la préparation d’un hébergement Node.js. Les secrets et les données de travail sont exclus du dépôt.

GitHub Pages continue de servir le site vitrine. L’administration nécessite un serveur pour la connexion, les fichiers et l’enregistrement ; les instructions sont dans le README du panneau.
